# 症状速查表

按现象定位原因。本页可独立引用，不依赖其他章节。

> 前置说明：漫画阅读器不含内容，它按「图源配置」去源站点取数据。一份图源在语义上包含
> **搜索入口 → 结果解析 → 目录接口 → 图片地址** 四个环节。看到什么症状，就对应到哪个环节断了。

---

## 主表

| 症状 | 断掉的环节 | 大概率原因 | 能否在客户端侧解决 | 处理 |
|---|---|---|---|---|
| 搜索没有任何结果（所有源） | — | 网络不通 | 可能 | 见下方「网络层排查」 |
| 搜索没有任何结果（个别源） | ① 搜索入口 | 源指向的站点停服或换域名 | 否 | 删源 |
| 搜到了，结果列表为空或错乱 | ② 结果解析 | 站点改版，解析规则对不上 | 否 | 换源 |
| 搜得到，点开详情页一片空白 | ③ 目录接口 | 详情接口失效 | 否 | 换源 |
| 有目录，点章节白屏 / 一直转圈 | ④ 图片地址 | 图床防盗链（`Referer` 校验） | **否** | 换源 |
| 有目录，点章节提示错误 | ④ 图片地址 | 图床要求鉴权或已下线 | 否 | 换源 |
| 只有某几章没图 | ④ 图片地址 | 源站点自身数据缺章 | 否 | 换源 |
| 昨天正常，今天全部失效 | ①②③④ 全部 | 源站点停服、换域名、加访问验证 | 否 | 删源 |
| 图片模糊、压缩严重 | ④ 图片地址 | 源使用低清图 | 否 | 换源（不影响功能） |
| 加载很慢但最终出图 | ④ 图片地址 | 高峰期限速、跨境链路 | 部分 | 换时段重试 |
| 同一本书在 A 源正常、B 源打不开 | ② 或 ③ | B 源的该书被下架 | 否 | 换 A 源读这本书 |
| 导入时报格式错误 | — | 文件损坏、格式与客户端不匹配 | 是 | 核对文件类型（`.txt` / `.json`），重新导出 |

---

## 一条关键区分

**能出目录但看不到图 = 图床层问题；连目录都出不来 = 站点层问题。**

这两个环节是分离的。目录接口通，说明客户端能正常访问源站点、请求头也没被拦；
只有图片请求被拒，说明限制发生在图床这一层，而不是客户端或网络。

这个区分决定了要不要浪费时间去重装、清缓存、换网络——上述动作对图床层问题全部无效。

## 判定依据

| 观察结果 | 说明 | 结论 |
|---|---|---|
| 目录加载正常 + 图片白屏 | 站点可达，图床拒绝 | 第三类失效（图床防盗链） |
| 目录加载正常 + 图片部分正常 | 部分图床节点异常 | 源侧问题，换源 |
| 目录空白 + 图片无从加载 | 详情接口失效 | 第一类失效（整源失效：目录接口对不上） |
| 搜索无结果 + 其他源也搜不到 | 网络层 | 见下节 |

---

## 网络层排查

**只在「所有源同时失效」时才需要走这一步。** 单个源失效不适用。

按顺序做，每做一项立即重测：

1. **关闭代理后重试**
   全局代理可能让部分站点反而访问不了。开、关两种状态各测一次，不要只测一种。

2. **Wi-Fi 与移动数据各测一次**
   部分宽带运营商会拦截特定域名或对特定域限速，切换网络能直接区分出来。

3. **换时间段**
   晚间高峰期的限速会让图片加载超时，表现与白屏一致，但实际是慢而非断。
   隔几个小时再试一次即可区分。

4. **核对客户端版本**
   以上三项都做过仍全部失效，才考虑客户端。
   对照官方更新日志确认当前版本，并检查该版本是否有已知的图源兼容问题。

## 什么条件下可以删源

满足**全部三条**再删，缺一条都可能是误判：

- [ ] 连续 **三天** 都是同样的失败状态
- [ ] 更换 **不同作品** 测试后仍然失败
- [ ] **清空缓存** 后重进依然失败

同时满足，说明该源的配置与源站点的实际结构已长期不匹配，无保留价值。

---

## 常见误判

| 做法 | 为什么是错的 |
|---|---|
| 只测一本书就判定源失效 | 可能只是那本书在该源被下架（第二类失效），源本身完好 |
| 打不开就重装客户端 | 四类失效中至少三类与客户端无关 |
| 清缓存试图修复白屏 | 防盗链是图床的服务端策略，本地缓存与它无关 |
| 只装一个源 | 任何源都会失效，追更作品应至少有两个可用来源 |
| 看到「最新合集」就整包导入 | 合集被反复转载，失效比例随转载次数上升；且失效源会污染搜索结果 |
